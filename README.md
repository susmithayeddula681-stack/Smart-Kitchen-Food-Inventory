# Smart Kitchen Food Inventory Dashboard

## 📌 Project Overview

Smart Kitchen Food Inventory Dashboard is an interactive Power BI project designed to analyze household food inventory data.

The dashboard provides insights into food purchases, consumption, remaining quantity, expiry status, food categories, sub-categories, food items, states, and regions.

## 🎯 Objectives

- Analyze food purchasing patterns
- Track quantity purchased and consumed
- Monitor remaining food quantity
- Monitor food expiry status
- Analyze food categories and sub-categories
- Compare food purchasing patterns across regions and states
- Build an interactive Power BI dashboard

## 🗂️ Dataset

The project uses an Excel dataset containing three main tables:

- Food Inventory
- Households
- Food Items

## 🧹 Data Preparation

Data was cleaned and transformed using Power Query.

The data preparation process included:

- Removing duplicate records
- Handling missing values
- Correcting data types
- Cleaning text fields
- Preparing data for analysis

## 🔗 Data Modeling

The Power BI data model includes relationships between:

- Food Inventory
- Households
- Food Items
- Date table

## 📊 Dashboard Features

The dashboard includes:

- KPI cards for purchased and consumed quantities
- Remaining quantity analysis
- Expiry status monitoring
- Category-wise analysis
- Sub-category analysis
- Top food items by quantity purchased
- Monthly purchase trend
- Region-wise analysis
- State-wise filtering
- Interactive slicers

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Power BI
- DAX

## 📷 Dashboard Preview

The final dashboard provides an interactive view of household food inventory, purchase patterns, consumption, remaining stock, expiry status, and regional analysis.
